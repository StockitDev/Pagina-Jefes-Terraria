Sobre el proyecto

Terraria Library muestra información de los jefes desde una base de datos MySQL en una página que puedes buscar. Está construida con herramientas distintas para organizar el contenido, darle diseño, agregar interacción y conectarse a la base de datos.

Estructura de la página

HTML organiza el encabezado, la búsqueda, la lista de jefes y sus detalles. Esta explicación está en una página aparte.

<main>
  <section class="intro">...</section>
  <section class="workspace">
    <aside>Lista de jefes</aside>
    <article>Detalles del jefe</article>
  </section>
</main>

Las etiquetas semánticas como main, section, aside y article agrupan el contenido relacionado y hacen que el código sea más fácil de seguir.

Diseño visual

CSS define los colores, espacios y tipografía. El verde salvia, el café y la fuente pixelada VT323 dan identidad al sitio.

La lista y los detalles usan dos columnas; en pantallas pequeñas, @media las apila.

.workspace {
  display: grid;
  grid-template-columns: 280px minmax(0, 1fr);
}

@media (max-width: 720px) {
  .workspace { grid-template-columns: 1fr; }
}

Búsqueda y detalles de los jefes

JavaScript carga los datos, filtra jefes y muestra sus estadísticas y recompensas. Todo se actualiza sin recargar la página.

const response = await fetch(
  "http://127.0.0.1:3000/api/data"
);
const data = await response.json();

La API y MySQL

Un servidor Node.js con Express ofrece /api/data. Consulta seis tablas de MySQL y envía sus registros a la página.

Funciones y variables

Además de las operaciones básicas, este proyecto usa herramientas para pedir datos, relacionarlos y mostrarlos.

fetch() y response.json()Piden datos a la API y convierten la respuesta JSON en datos de JavaScript.
filter(), find() y map()Filtran resultados, encuentran registros relacionados y crean elementos para la lista.
Promise.all()Permite consultar varias tablas al mismo tiempo.
Intl.NumberFormat()Da formato legible a las estadísticas numéricas.
dataGuarda los datos recibidos de la API.
selectedId y queryGuardan el jefe seleccionado y el texto escrito en la búsqueda.
process.envPermite al servidor leer su configuración desde variables de entorno.

¿Qué es JSON?

JSON es un formato de texto para organizar e intercambiar datos. La API lo usa para enviar a la página los jefes y sus registros relacionados.

{
  "bosses": [
    {
      "Boss_Name": "King Slime",
      "Life_Amount": 2000
    }
  ]
}

En la respuesta real, bosses y las demás listas contienen los registros leídos desde MySQL.

¿Para qué sirve .env?

.env guarda la configuración privada que necesita el backend para conectarse a MySQL, separada del código. Este proyecto lo usa para el servidor, el usuario y la base de datos; la contraseña también puede ir ahí.

DB_HOST=localhost
DB_USER=tu_usuario
DB_PASSWORD=tu_contraseña
DB_NAME=tu_base_de_datos

El archivo está excluido de Git para evitar publicar esos datos.

Cómo llegan los datos

  1. El navegador pide los datos a la API.
  2. Express consulta MySQL y devuelve JSON.
  3. JavaScript muestra la lista y los detalles.

Así, la página muestra los datos actuales de la base MySQL.

En resumen

HTML organiza el contenido, CSS le da forma a la interfaz, JavaScript agrega interacción y la API de Node.js conecta la página con MySQL.
